# Vyro Studio – Agency Website

A modern agency website built with React and TypeScript, with a focus on frontend development, Docker containerization, and cloud deployment using AWS.

## Project Overview

Vyro Studio is a digital agency website designed to deliver a professional online presence through a modern and responsive user interface.

This project also explores containerization and cloud deployment workflows.

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- GSAP
- Docker
- Docker Hub
- AWS EC2
- Nginx
