# 08 – Testing and Verification

## 1. Overview

Testing and verification will be performed throughout the development and deployment lifecycle.

## 2. Frontend Testing

- Verify that the website loads correctly.
- Check navigation and interactive elements.
- Verify responsive layouts.
- Run the production build.

## 3. Docker Testing

- Verify successful image creation.
- Verify container startup.
- Check container status.
- Test application access through the mapped port.

## 4. Docker Hub Verification

- Verify repository availability.
- Confirm successful image publishing.
- Check the published image tag.

## 5. AWS Verification

- Verify EC2 connectivity.
- Check Docker service availability.
- Verify container execution.
- Test website accessibility through the public IP.

## 6. Results

Actual test results and screenshots will be added after each verification stage is completed.
