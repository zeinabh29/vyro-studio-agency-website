# 09 – Troubleshooting

## 1. Overview

This document records technical issues, their causes, and the solutions applied during development and deployment.

## 2. Frontend Issues

Issues related to npm, Vite, TypeScript, and production builds will be documented here.

## 3. Docker Issues

Issues related to image creation, container execution, ports, and Docker configuration will be documented here.

## 4. Docker Hub Issues

Authentication, repository access, image tagging, and push errors will be recorded here.

## 5. AWS Issues

SSH connectivity, security groups, Docker installation, and deployment issues will be documented here.

## 6. Issue Tracking Template

For each issue, record:

- Problem description.
- Error message.
- Root cause.
- Resolution.
- Verification result.
