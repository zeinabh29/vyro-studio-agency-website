# 02 – Technology Stack

## 1. Overview

Vyro Studio is developed using a modern frontend technology stack.

## 2. Core Technologies

| Technology | Purpose |
|---|---|
| React 18 | Building reusable UI components |
| TypeScript | Static typing |
| Vite 5 | Development server and production builds |
| Tailwind CSS 3 | Styling and responsive layouts |
| React Router DOM | Client-side navigation |

## 3. Animation and UI Libraries

| Library | Purpose |
|---|---|
| Framer Motion | Animations and transitions |
| GSAP | Advanced animations |
| Lucide React | Interface icons |

## 4. Development Tools

| Tool | Purpose |
|---|---|
| npm | Dependency management |
| PostCSS | CSS processing |
| Autoprefixer | CSS vendor prefixes |
| Vite React Plugin | React integration |

## 5. Available Scripts

| Command | Description |
|---|---|
| npm run dev | Starts the development server |
| npm run build | Generates the production build |
| npm run preview | Previews the production build |
| npm run lint | Runs TypeScript type checking |

## 6. Build Configuration

- Development port: 5173
- Development host: 0.0.0.0
- Production output directory: dist

## 7. Conclusion

The selected technologies provide the foundation for developing, building, and preparing the website for production deployment.
