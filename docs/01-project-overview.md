# 01 – Project Overview

## 1. Introduction

Vyro Studio is a modern digital agency website developed to present the agency's identity, services, and digital presence through a professional web experience.

This project combines modern frontend development practices with containerization and cloud deployment workflows.

## 2. Project Objectives

The main objectives of this project are:

- Develop a modern and responsive agency website.
- Build an organized frontend application using React and TypeScript.
- Create an optimized production build using Vite.
- Containerize the application using Docker.
- Publish Docker images through Docker Hub.
- Deploy the containerized application on AWS EC2.
- Document the complete development and deployment workflow.

## 3. Project Scope

The project covers two main areas:

### Frontend Development
- Website development.
- Component-based architecture.
- Responsive user interface.
- Frontend animations and interactions.

### Cloud & DevOps
- Docker image creation.
- Container management.
- Docker Hub image publishing.
- AWS EC2 infrastructure configuration.
- Cloud deployment and testing.

## 4. Project Status

The frontend application and initial local development environment have been established.

The Docker configuration and cloud deployment workflow will be implemented and documented in subsequent stages.

## 5. Documentation Scope

This documentation records the technical decisions, implementation procedures, commands, screenshots, and verification results throughout the project lifecycle.
